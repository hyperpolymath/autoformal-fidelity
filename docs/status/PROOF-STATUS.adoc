=== Negative control (not a theorem, not counted above)

`tests/reject/RoundTripIsFidelity.agda` states that a passing round trip implies coverage. That claim is false, so the module must fail to check. `scripts/check-agda.sh` passes only if the module is refused at its declaration with a checked error. It is a control that the checker rejects the translator's fallacy. It proves nothing about the artefact.
